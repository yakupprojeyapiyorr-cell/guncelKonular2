# Arşivlenmiş Bileşenler

Bu klasördeki bileşenler gelecekteki AI/ders modülü için hazırlanmıştır.
Backend API'leri (`/lessons`, `/ai/chat`, `/ai/explain`) henüz implemente edilmediği için
route'lara bağlanmamıştır. AI API entegrasyonu tamamlandığında buradan geri alınabilir.

- `LessonDetails.jsx` — Ders/video oynatıcı
- `AiChatPanel.jsx` — Konu bazlı AI sohbet paneli
- `StudyAiChat.jsx` — AI açıklama/sohbet bileşeni
